# Project LockStep

**Lock every door. Add a second key.**

**Author:** Kabo Ernest Ntalamo  
**Module:** Introduction to Computer Cyber Security (C5-ICS-23)  
**Assessment:** End Assessment Project  
**Project:** Cybersecurity Awareness Campaign

## Purpose

Project LockStep helps students and everyday internet users protect their
accounts from password attacks, phishing and identity theft. It promotes
strong, unique passwords, multi-factor authentication (MFA) (NIST, n.d.),
software updates and prompt reporting of suspicious activity.

This repository contains practical resources that support the Project LockStep
campaign brochure.

## How to Use the Resources

1. Read [Phishing Awareness](docs/phishing-awareness.md) to learn how to
   recognise suspicious messages and respond safely.
2. Work through the [Cybersecurity Checklist](checklists/cybersecurity-checklist.md)
   to review the security of your accounts and devices.
3. Use the [Incident Report Template](templates/incident-report-template.md)
   to record a suspected incident before reporting it through an official
   support channel.
4. Open the [Project LockStep brochure](brochure/project-lockstep-brochure.pdf)
   for a visual summary of the campaign.

## Reporting Safely

Do not publish completed incident reports, passwords, verification codes,
recovery codes or other sensitive personal information in this public
repository. Report incidents through your university’s official IT helpdesk or
the affected service provider’s verified support channel.
